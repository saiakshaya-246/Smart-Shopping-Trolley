# Smart Shopping Trolley

A smart shopping trolley that uses RFID/barcode scanning to identify products, update the shopping cart in real time, and automate the billing process. The system also provides digital receipts, UPI QR payment, and AI-powered shopping suggestions through a web dashboard.

## Features

* RFID-based real-time product identification
* Barcode scanning for product detection
* Live cart and inventory updates
* Automatic bill calculation with GST
* Add, remove, and reset cart functionality
* LCD display for cart information and total amount
* Buzzer alerts for trolley operations
* Digital receipt generation
* UPI QR code payment integration
* AI-powered shopping suggestions and promotions
* Load-cell based support for detecting unscanned items
* React-based dashboard for monitoring cart activity

## How It Works

1. A customer scans a product using the RFID reader or barcode scanner.
2. The product details are identified and added to the cart.
3. The web dashboard updates the cart and total amount in real time.
4. The LCD displays the relevant cart information.
5. GST is automatically calculated and included in the bill.
6. The system generates a digital receipt.
7. The customer can complete the payment using a UPI QR code.
8. AI-powered suggestions can recommend alternative products, promotions, and cost-saving options.
